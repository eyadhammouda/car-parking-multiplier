# Car Parking Multiplier

A small React + TypeScript front end for a parking gate: a welcome screen with
an "Open Gate" button, an entrance view that shows the assigned section and
plate, and an exit page.

Built with [Vite](https://vite.dev/) and tested with [Vitest](https://vitest.dev/).
Requires Node 20.19 or newer.

## Available Scripts

In the project directory, you can run:

### `npm start`

Runs the app in development mode with hot reloading.
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

### `npm test`

Runs the test suite in watch mode. Use `npx vitest run` for a single pass.

### `npm run build`

Type-checks the project and builds it for production into the `build` folder.

### `npm run preview`

Serves the production build locally so you can check it before deploying.
